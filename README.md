# 🏎️ City Racing 3D

## 📌 Sobre o jogo
 City Racing 3D é um jogo de direção em 3D no qual o jogado controla uma Ferrari e percorre uma cidade com ruas, prédios e árvores. O objetivo é dirigir pelo mapa e chegar aos objetivos indicados pelo GPS.

## 🎮 Funcionalidades
- Cenário de cidade em 3D.
- Carro Ferrari controlado pelo jogador.
- Sistema de GPS com indicação de distância.
- Painel com velocidade, dinheiro, corridas e passageiros.
- Controles para acelerar, frear e dar ré.
- Direcionamento do carro para a esquerda e para a direita.
- Interface adaptada para celular.

## 🕹️ Controles

- **◀ / ▶:** virar o carro.
- **Acelerar:** aumentar a velocidade.
- **Frear:** diminuir a velocidade.
- **Ré:** movimentar o carro para trás.
- **F:** utilizar a função indicada pelo jogo.

## 🛠️ Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Three.js
- WebGL

## 🎯 Objetivo
Dirigir pela cidade, acompanhar o GPS e completar os objetivos do jogo.
